## 🎯 Core Security Capabilities

### 🚨 SOC Engineering & SOAR Automation
- Architect and operate integrated SOC stacks combining **Wazuh** (SIEM/XDR), **Shuffle** (SOAR), **DFIR-IRIS** (incident case management), and **MISP** (threat intelligence).
- Automate alert enrichment, IOC correlation, ticketing, and real-time notification workflows using Python, Bash, n8n, and structured LLM triage pipelines.

### ⚡ Incident Response & Threat Defense
- Perform real-time alert triage, anomaly detection, and root-cause analysis across high-traffic public-sector and enterprise infrastructure.
- Correlated **Cloudflare** edge logs with **Wazuh** telemetry to detect and mitigate a live multi-IP **Layer 7 DDoS attack** in production.
- Administer endpoint protection and malware investigation workflows across **Microsoft Defender** and **ESET EDR**.

### 🔎 VAPT & Vulnerability Management
- Conduct manual and automated **Vulnerability Assessments and Penetration Testing (VAPT)** across web apps, APIs, mobile apps, servers, and networks using **Burp Suite, Nessus, Acunetix, Nmap, and Trivy**.
- Prioritize critical findings (including **CVSS 9.1+** vulnerabilities), validate fixes, and coordinate security patch management across government and financial-sector environments.

### 📋 Governance, Compliance & Security Awareness
- Support **ISO/IEC 27001, NIST, and OWASP** security governance through control assessments, audit evidence collection, compliance gap analysis, and remediation tracking.
- Harden IAM, OAuth 2.0 / Keycloak SSO, WAF rules, TLS configurations, Kubernetes RBAC, and secrets management.
- Author internal cybersecurity awareness content to strengthen organizational security culture.
